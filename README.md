# Электронная библиотека


**Тема:** Программная реализация каталога электронной библиотеки с использованием динамических структур данных.

---

## Описание проекта

Веб-приложение для управления каталогом библиотеки. Позволяет вести учёт книг и читателей, оформлять выдачу и возврат книг, выполнять поиск и сортировку, а также просматривать статистику.

Данные хранятся в браузере с помощью **localStorage** и сохраняются между сеансами.

### Основные возможности

- **Книги** — добавление, удаление, просмотр списка, сортировка по автору или году издания
- **Читатели** — добавление, удаление, просмотр списка
- **Выдача и возврат** — оформление выдачи книги читателю, возврат книги, журнал всех операций
- **Поиск** — поиск книг по названию или автору (поиск по подстроке)
- **Статистика** — общее количество книг, количество выданных/доступных, распределение по жанрам


## Запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/getmananastyasia/kursovaya-library-.git
cd kursovaya-library-

# 2. Открыть веб-интерфейс в браузере
open web/index.html        # macOS
xdg-open web/index.html    # Linux
start web/index.html        # Windows
```

Никакой установки, сборки или сервера не требуется — приложение полностью работает в браузере.

## Как пользоваться

### Навигация

Переключение между разделами осуществляется через боковое меню. Также доступны горячие клавиши **1–5** для быстрого переключения между страницами.

### Пример сценария работы

1. Откройте `web/index.html` в браузере
2. Перейдите в раздел **Книги** → нажмите **Добавить книгу** → заполните форму
3. Перейдите в раздел **Читатели** → нажмите **Добавить читателя** → введите ФИО и телефон
4. Перейдите в раздел **Выдача и возврат** → нажмите **Выдать книгу** → укажите книгу, читателя и дату
5. Перейдите в раздел **Поиск** → найдите книгу по названию или автору
6. Перейдите в раздел **Статистика** — посмотрите сводку по библиотеке

---

## Хранение данных

Все данные автоматически сохраняются в **localStorage** браузера. Данные сохраняются между перезагрузками страницы и сеансами браузера.

> **Важно:** при очистке данных браузера (кэш, куки, localStorage) данные библиотеки будут удалены.
